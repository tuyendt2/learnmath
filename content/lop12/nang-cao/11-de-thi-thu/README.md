# Phần 11. Đề thi thử

Gồm **10 đề**, mỗi đề **10 câu**, câu thứ k ứng với chủ đề k. Mỗi đề có lời giải chi tiết ở cuối file. Đề có dạng đề thi học sinh giỏi Toán 12 cấp tỉnh.

- **Thời gian:** 180 phút/đề.
- **Thang điểm:** mỗi câu 1 điểm, tổng 10 điểm. Câu có nhiều ý thì chia đều điểm cho các ý.
- **Độ khó:** đề 1–3 mức khá, đề 4–7 mức giỏi, đề 8–10 có câu khó để chọn đội tuyển.

## Danh sách đề

| Đề | Điểm nhấn |
|---|---|
| [Đề 1](de-01.md) | Hàm đặc trưng $t^3 + t$; $e^x \ge 1 + x + \frac{x^2}{2}$; tích năm số nguyên liên tiếp |
| [Đề 2](de-02.md) | Tiếp tuyến có hệ số góc nhỏ nhất; $\int_0^1 x\ln(1 + x)\,dx$; mặt cầu tiếp xúc ba mặt tọa độ |
| [Đề 3](de-03.md) | $\sin x > x - \frac{x^3}{6}$; so sánh $3^{\sqrt{2}}$ và $2^{\sqrt{3}}$; $d(AC', BD)$ trong lập phương |
| [Đề 4](de-04.md) | Ba cực trị tạo tam giác đều; dãy hội tụ về $\sqrt{3}$; nghịch lý ngày sinh |
| [Đề 5](de-05.md) | $8x^3 + 2x = (x + 3)\sqrt{x + 2}$; trụ nội tiếp nón; phương trình Pell |
| [Đề 6](de-06.md) | Tổng Riemann ra $\ln 2$; tích phân đối xứng; mặt cầu ngoại tiếp lăng trụ đều |
| [Đề 7](de-07.md) | $3^x = 2x + 1$; mặt cầu nội tiếp hình nón; Bayes với hai xạ thủ |
| [Đề 8](de-08.md) | Đường thẳng qua hai cực trị; tổng Riemann với sin; chia nhóm |
| [Đề 9](de-09.md) | Ba cực trị tạo tam giác vuông; $\int_0^1\frac{dx}{x^2 + x + 1}$; xác suất có điều kiện với đồng xu |
| [Đề 10](de-10.md) | $AB$ nhỏ nhất; $x^x \ge e^{-1/e}$; số nghiệm của $2^x = x^2$ |

## Cách luyện đề hiệu quả

1. **Bấm giờ đúng 180 phút**, làm trên giấy; không cần làm theo thứ tự.
2. Câu chứng minh: trình bày đủ lý do; câu hình học vẽ hình chính xác.
3. Chấm theo lời giải. Câu nào sai thì **quay lại chủ đề tương ứng**.
4. Một tuần sau, làm lại các câu đã sai.
