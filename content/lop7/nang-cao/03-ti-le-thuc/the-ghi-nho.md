## Tỉ lệ thức

### Tính chất cơ bản của tỉ lệ thức $\frac ab = \frac cd$ là gì?
$ad = bc$ (tích ngoại tỉ bằng tích trung tỉ).

### Từ $ad = bc$ (các số khác $0$) lập được những tỉ lệ thức nào?
$\frac ab = \frac cd$, $\frac ac = \frac bd$, $\frac db = \frac ca$, $\frac dc = \frac ba$.

### Từ $2x = 3y$ viết thành tỉ lệ thức thế nào?
$\frac x3 = \frac y2$. Hệ số của $x$ đứng dưới $y$ và ngược lại.

### Từ $\frac ab = \frac cd$ suy ra $\frac{a + b}{b}$ bằng gì?
$\frac{a + b}{b} = \frac{c + d}{d}$ (cộng $1$ vào hai vế). Tương tự $\frac{a - b}{b} = \frac{c - d}{d}$.

### Từ $a^2 = bc$ suy ra tỉ lệ thức nào?
$\frac ac = \frac ba$ (hoặc $\frac ab = \frac ca$).

## Dãy tỉ số bằng nhau

### Phát biểu tính chất dãy tỉ số bằng nhau?
$\frac ab = \frac cd = \frac ef = \frac{ma + nc + pe}{mb + nd + pf}$, với mẫu khác $0$.

*Vì sao:* đặt giá trị chung là $k$ thì $a = kb$, $c = kd$, $e = kf$, nên tử tổng hợp bằng $k$ lần mẫu tổng hợp.

### Đề cho $2x + 3y - z = 24$ và $\frac x2 = \frac y3 = \frac z5$ thì chọn hệ số thế nào?
Nhân tử và mẫu của từng tỉ số với hệ số tương ứng: $\frac{2x}{4} = \frac{3y}{9} = \frac z5 = \frac{2x + 3y - z}{4 + 9 - 5}$.

### Có được viết $\frac x2 = \frac y5 = \frac{xy}{10}$ không?
Không. Tính chất dãy tỉ số chỉ cộng, trừ tử và mẫu. Với tích hay bình phương, hãy **đặt $k$**.

### Phương pháp đặt $k$ là gì? Khi nào nên dùng?
Đặt giá trị chung bằng $k$, thay $a = bk$, $c = dk$, ... vào biểu thức. Dùng khi đề có tích, bình phương, hoặc khi chứng minh tỉ lệ thức.

### Giải xong $k^2 = 4$ cần chú ý gì?
Có hai giá trị $k = 2$ và $k = -2$, cho hai bộ nghiệm.

### Nối hai tỉ lệ thức $\frac x3 = \frac y4$ và $\frac y5 = \frac z7$ thế nào?
Đưa $y$ về cùng mẫu $20$: $\frac{x}{15} = \frac{y}{20} = \frac{z}{28}$.

### Đổi $2x = 3y = 5z$ thành dãy tỉ số thế nào?
Chia các vế cho BCNN$(2, 3, 5) = 30$: $\frac{x}{15} = \frac{y}{10} = \frac z6$.

### Dạng $\frac{x - 1}{2} = \frac{y - 2}{3} = \frac{z - 3}{4}$ thì làm gì?
Đặt $k$: $x = 2k + 1$, $y = 3k + 2$, $z = 4k + 3$, rồi thay vào điều kiện còn lại.

## Trường hợp đặc biệt

### Khi dùng $\frac{a + c + e}{b + d + f}$ phải kiểm tra điều gì?
Tổng mẫu $b + d + f \ne 0$. Nếu có thể bằng $0$, phải xét riêng trường hợp đó.

### $\frac{a}{b + c} = \frac{b}{c + a} = \frac{c}{a + b}$ thì mỗi tỉ số bằng bao nhiêu?
Bằng $\frac12$ nếu $a + b + c \ne 0$, bằng $-1$ nếu $a + b + c = 0$.

### Dãy $\frac ab = \frac bc = \frac ca$ (với $a + b + c \ne 0$) cho kết luận gì?
Mỗi tỉ số bằng $\frac{a + b + c}{b + c + a} = 1$, nên $a = b = c$.

### Dạng $\frac{a + b - c}{c} = \frac{b + c - a}{a} = \frac{c + a - b}{b}$ có mẹo gì?
Cộng $2$ vào mỗi tỉ số để các tử cùng bằng $a + b + c$. Rồi xét $a + b + c \ne 0$ (khi đó $a = b = c$) và $a + b + c = 0$.

### Mẹo khi tổng các tử không triệt tiêu, như $\frac{bz - cy}{a} = \frac{cx - az}{b} = \frac{ay - bx}{c}$?
Nhân tử và mẫu với $a$, $b$, $c$. Tổng các tử mới bằng $0$, mẫu $a^2 + b^2 + c^2 > 0$, nên mọi tỉ số bằng $0$.

### Dãy tỉ số mà giá trị chung cũng chứa ẩn, như $\frac{x}{y+z+1} = \dots = x + y + z$, giải thế nào?
Tính giá trị chung bằng tổng tử chia tổng mẫu, rồi thay $y + z = S - x$ để mỗi phương trình còn một ẩn. Xét riêng $x + y + z = 0$.
