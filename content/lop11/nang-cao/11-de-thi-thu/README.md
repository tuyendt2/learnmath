# Phần 11. Đề thi thử

Gồm **10 đề**, mỗi đề **10 câu**, câu thứ k ứng với chủ đề k. Mỗi đề có lời giải chi tiết ở cuối file. Đề có dạng đề thi học sinh giỏi Toán 11 cấp tỉnh.

- **Thời gian:** 180 phút/đề.
- **Thang điểm:** mỗi câu 1 điểm, tổng 10 điểm. Câu có nhiều ý thì chia đều điểm cho các ý.
- **Độ khó:** đề 1–3 mức khá, đề 4–7 mức giỏi, đề 8–10 có câu khó để chọn đội tuyển.

## Danh sách đề

| Đề | Điểm nhấn |
|---|---|
| [Đề 1](de-01.md) | Tổng côsin; dãy $u_{n+1} = \sqrt{u_n + 2}$; hai tam giác đều dựng ngoài |
| [Đề 2](de-02.md) | Truy hồi tuyến tính cấp hai; $\frac{1}{x} + \frac{4}{y} \ge 9$; vị tự tâm tiếp điểm |
| [Đề 3](de-03.md) | Nhận dạng tam giác vuông; chọn bi đủ ba màu; góc trong lăng trụ đều |
| [Đề 4](de-04.md) | $\tan x + \cot x = 4$; $2^n + 1$ chia hết cho 9; $MA = 1$, $MB = 2$, $MC = 3$ trong hình vuông |
| [Đề 5](de-05.md) | Đẳng thức Cassini; dãy Newton hội tụ về $\sqrt{2}$; quỹ tích trung điểm |
| [Đề 6](de-06.md) | Kẹp tổng; $(x - 2)(2^x + x - 1) = 0$; phân giác ngoài và cực trị |
| [Đề 7](de-07.md) | $\tan A + \tan B + \tan C$; hệ số trong $(1 + x + x^2)^5$; $\frac{1}{MD} = \frac{1}{MB} + \frac{1}{MC}$ |
| [Đề 8](de-08.md) | $\sin^4 x + \cos^4 x$; tổng lũy thừa theo Fermat; dựng đoạn bằng tịnh tiến |
| [Đề 9](de-09.md) | $\cos\frac{\pi}{7} - \cos\frac{2\pi}{7} + \cos\frac{3\pi}{7}$; $n^4 + 4^n$; hai hình vuông chung đỉnh |
| [Đề 10](de-10.md) | $u_{n+1} = u_n^2 - 2$; số Catalan; điểm Fermat |

## Cách luyện đề hiệu quả

1. **Bấm giờ đúng 180 phút**, làm trên giấy; không cần làm theo thứ tự.
2. Câu chứng minh: trình bày đủ lý do từng bước; câu hình học vẽ hình chính xác.
3. Chấm theo lời giải. Câu nào sai thì **quay lại chủ đề tương ứng**.
4. Một tuần sau, làm lại các câu đã sai.
